# زادُ الروح

تطبيق Flutter عربي لأندرويد وآيفون، يعمل بالمحتوى المدمج والحفظ المحلي، دون حساب مستخدم أو إعلانات أو سيرفر تشغيل. التصميم واللوجو والخطوط الأصلية محفوظة في المشروع.

## الحالة الحالية — APK جديد لاختبار أندرويد، ٩ أكتوبر ٢٠٢٦

- أساس التطبيق والتنقل والمظهر العربي، وقاعدة SQLite لحفظ التقدم والتفضيلات والجلسات والمفضلة.
- نص القرآن العثماني الأصلي من Tanzil v1.1: ١١٤ سورة و٦٢٣٦ آية، مع فهرس ٣٠ جزءًا وحدود ٦٠٤ صفحات. النص والتراخيص وبصمات الملفات محفوظة دون تغيير.
- بيانات GeoNames الأصلية لـ٣٤١٤٩ مدينة مع المناطق الزمنية ونسب المصدر.
- مصحف مصوّر كامل: ٦٠٤ صفحات من مصحف المدينة برواية حفص، مدمجة للعمل دون إنترنت، مع التالي والسابق والتكبير. عنوان السورة وأدوات القراءة خارج صورة الصفحة حتى يظهر أول سطر.
- فهرس القرآن والبحث المحلي واستكمال القراءة والعلامات والمفضلة؛ تلاوة كاملة للسورة بصوت مشاري العفاسي عبر الإنترنت، مع تشغيل وإيقاف وإيقاف مؤقت. التلاوة ليست متزامنة مع الصفحة المصوّرة.
- اختيار المدن العالمية وحفظ طريقة حساب الصلاة والمنطقة الزمنية، مع التعامل مع التوقيت الصيفي وحالات تعذر الحساب.
- ٣٢١٣ حديثًا من موسوعة الأحاديث النبوية HadeethEnc، مع البحث والتخريج والدرجة وروابط المصدر.
- حصن المسلم: ٢٦٧ ذكرًا ودعاءً في ١٣٢ بابًا، مع نص المصدر وحواشيه. قوائم الصباح والمساء وأذكار بعد الصلاة تحفظ إنجاز اليوم، وتبدأ قائمة جديدة في يوم المدينة التالي. الدعاء اليومي وحفظ تقدم القراءة مستقلان عن السجل القديم.
- ثلاثة تسجيلات أذان مرخّصة مدمجة، مع معاينة الصوت وحفظ الاختيار وإدارة تشغيل مشتركة مع تلاوة القرآن لمنع تداخل الصوت.
- تنبيهات الصلاة الأصلية في أندرويد مربوطة بالإعدادات وإدارة الصوت وإعادة الضبط، مع اختبارات الصلاحيات وسباقات العمليات واستعادة الحالة. تجربة الصوت والتنبيهات على هاتف فعلي ما زالت مطلوبة. تطوير iOS متوقف مؤقتًا بطلب المالك.

النسخة الجديدة: [APK 0.2.0+2](dist/android/zad-alruh-0.2.0+2-debug.apk). نجحت ٥٢٨ تجربة Flutter والتحليل والبناء؛ فُحصت ٦١٩ نسخة ملف داخل الحزمة، منها صفحات المصحف الـ٦٠٤. راجع [تقرير النسخة](docs/ANDROID-APK-2026-10-09.md) لنتائج التوقيع وحدود توافق 16KB. هذه نسخة اختبار وليست إصدار متجر.

توجد [معاينة مرئية لأندرويد وآيفون](docs/preview/index.html) تتيح التنقل بين لقطات الشاشات الفعلية من Flutter. لقطة الآيفون تحاكي مقاس الجهاز ونمط واجهته؛ هي ليست تشغيلًا لمحاكي iOS أو بناء iOS أصليًا. يمكن فتح الملف مباشرة في المتصفح، أو تشغيله محليًا بأمر `python -m http.server 8765 --directory docs/preview` من جذر المشروع. الملفات المحفوظة في `docs/preview` تمثل هذه المرحلة ويمكن تحديثها بعد كل مرحلة واجهة.

المحتوى الديني مأخوذ من ملفات المصادر المحفوظة وتراخيصها، ولا تُولّد نصوص دينية بديلة. راجع صفحة المصادر داخل التطبيق وملفات `docs/sources` للتوثيق وحدود الاستخدام.

## التشغيل والتحقق

الإصدارات والأدوات الفعلية موثقة في [دليل البيئة](docs/BUILD-ENVIRONMENT.md). على جهاز Windows الحالي يمكن تنفيذ تحليل Flutter واختباراته من `D:\tools\zad-alruh-workspace`، وهو رابط إلى نفس المشروع. بناء JNI اكتشف المسار العربي رغم الرابط؛ لذلك بُني APK الحالي من نسخة ملفات فعلية بمسار ASCII: `D:\tools\zad-android-apk-20261009`، بعد التحقق من تطابق ٨٣٣ ملفًا مع الأصل. المشروع الأصلي لم يُنقل. هذه النسخة لقطة ثابتة؛ يجب تحديثها من الأصل قبل بناء تغييرات لاحقة.

```powershell
flutter pub get
flutter analyze
flutter test
dart run tool/validate_content.dart --development
dart run tool/validate_content.dart --release
flutter build apk --debug
```

فحص `--release` يفشل حاليًا بسبب عدم اكتمال المراجعة البشرية المؤهلة للمحتوى؛ لا تُختلق موافقة بديلة. بناء نسخة تطوير لا يعني صلاحيتها للتقديم للمتاجر. إعدادات Java وAndroid المطلوبة موجودة في دليل البيئة. بناء وتوقيع iOS يحتاجان macOS وXcode.

## متطلبات الإصدار

مصادر الصور والأصوات والمحتوى وتراخيصها مدمجة وموثقة. تبقى المراجعة البشرية المؤهلة، واختبارات الأجهزة والصوت والتنبيهات وصفحات الذاكرة 16 KB، وحساب Google Play والتوقيع وبيانات الناشر ومعرّف التطبيق النهائي وروابط الدعم والخصوصية شروطًا للنشر العام. لا تُحفظ الأسرار أو مفاتيح التوقيع في المستودع، ولا ينشر المشروع تلقائيًا.
