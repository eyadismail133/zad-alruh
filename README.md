# زادُ الروح — Zad Al-Ruh

رفيق يومي للمسلم يعمل بدون إنترنت: المصحف المصوّر (مصحف المدينة، ٦٠٤ صفحة)، مواقيت الصلاة لأكثر من ٣٤ ألف مدينة مع الأذان، الأذكار وحصن المسلم، والأحاديث.

## التحميل (أندرويد)
آخر نسخة في صفحة **[Releases](https://github.com/eyadismail133/zad-alruh/releases/latest)**:
- `arm64-v8a` لأغلب الموبايلات، `armeabi-v7a` للقديمة، `universal` لو مش متأكد.

```bash
flutter pub get
flutter run
```
