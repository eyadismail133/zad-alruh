# زادُ الروح

تطبيق Flutter عربي لأندرويد وآيفون، يعمل بالمحتوى المدمج والحفظ المحلي، دون حساب مستخدم أو إعلانات أو سيرفر تشغيل. التصميم واللوجو والخطوط الأصلية محفوظة في المشروع.

## الحالة الحالية

- أساس التطبيق والتنقل والمظهر العربي، وقاعدة SQLite لحفظ التقدم والتفضيلات والجلسات والمفضلة.
- نص القرآن العثماني الأصلي من Tanzil v1.1: ١١٤ سورة و٦٢٣٦ آية، مع فهرس ٣٠ جزءًا وحدود ٦٠٤ صفحات. النص والتراخيص وبصمات الملفات محفوظة دون تغيير.
- بيانات GeoNames الأصلية لـ٣٤١٤٩ مدينة مع المناطق الزمنية ونسب المصدر.
- واجهة القرآن معتمدة بمراجعة GPT-6 Sol: الفهرس والبحث المحلي والانتقال للصفحات واستكمال القراءة وتحديد آية التوقف والعلامات المسماة والمصادر. نجح التحليل وكل الاختبارات الـ١١٣ وبناء أندرويد التجريبي.
- محرك مواقيت الصلاة المحلي وفهرس المدن العالمي اجتازا مراجعة GPT-6 Sol: طرق الحساب، المنطقة الزمنية للمدينة، التوقيت الصيفي، الحالات القطبية، والصلاة التالية. تعرض الشاشة الرئيسية وشاشة الصلاة الآن المواقيت المحسوبة للمدن الثماني المتاحة في الإعدادات، مع الصلاة القادمة والعد التنازلي وحالات تعذر الحساب. راجع GPT-6 Sol هذا الربط أيضًا، واجتاز المشروع ١٦٩ اختبارًا والتحليل وبناء APK تجريبي جديد. اختيار أي مدينة من الفهرس العالمي وحفظ إعدادات الحساب والتنبيهات لم يكتمل بعد.

توجد [معاينة مرئية لأندرويد وآيفون](docs/preview/index.html) تتيح التنقل بين لقطات الشاشات الفعلية من Flutter. لقطة الآيفون تحاكي مقاس الجهاز ونمط واجهته؛ هي ليست تشغيلًا لمحاكي iOS أو بناء iOS أصليًا. يمكن فتح الملف مباشرة في المتصفح، أو تشغيله محليًا بأمر `python -m http.server 8765 --directory docs/preview` من جذر المشروع. الملفات المحفوظة في `docs/preview` تمثل هذه المرحلة ويمكن تحديثها بعد كل مرحلة واجهة.

حدود صفحات الفهرس ليست صور مصحف. صور مصحف المدينة الـ٦٠٤ وتسجيلات الأذان والمحتوى المرخص للأذكار والأدعية والأحاديث لم تُضمّن بعد. يعرض التطبيق هذه الحالات بوضوح، ولا يستخدم نصوص التصميم أو محتوى ديني مولّدًا.

## التشغيل والتحقق

الإصدارات والأدوات الفعلية موثقة في [دليل البيئة](docs/BUILD-ENVIRONMENT.md). على جهاز Windows الحالي تُنفذ الأوامر من `D:\tools\zad-alruh-workspace`، وهو رابط إلى نفس المشروع يتجنب مشكلة Java مع المسار العربي.

```powershell
flutter pub get
flutter analyze
flutter test
dart run tool/validate_content.dart --development
dart run tool/validate_content.dart --release
flutter build apk --debug
```

فحص `--release` يفشل حاليًا عمدًا بسبب متطلبات المحتوى والحقوق والمراجعة البشرية الناقصة. بناء نسخة تطوير لا يعني صلاحيتها للتقديم للمتاجر. إعدادات Java وAndroid المطلوبة موجودة في دليل البيئة. بناء وتوقيع iOS يحتاجان macOS وXcode.

## متطلبات الإصدار

تبقى حقوق صور المصحف والأصوات والمحتوى الرقمي والمراجعة الشرعية البشرية، واختبارات الأجهزة والتنبيهات وصفحات الذاكرة 16 KB، وحسابات المتاجر والتوقيع ومعرّف التطبيق النهائي وروابط الدعم والخصوصية شروطًا للإصدار. لا تُحفظ الأسرار أو مفاتيح التوقيع في المستودع، ولا ينشر المشروع تلقائيًا.
