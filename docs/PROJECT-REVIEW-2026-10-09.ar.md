## النواقص والملاحظات — دون تنفيذ إصلاحها

1. **إصدار نهائي موقّع:** الحالي Debug ومعرفه `dev.zadalruh.zad_alruh`. إعدادات Release في `android/app/build.gradle.kts` تطلب توقيع المالك ومعرف إصدار صريحًا؛ `android/key.properties` غير موجود. التحميل المباشر لا يتطلب حساب Google Play، لكن إصدارًا عامًا مستقرًا وتحديثاته يحتاجان مفتاح توقيع ثابتًا.
2. **اختبار ميداني لأندرويد:** يلزم تجربة المصحف والخط والتلاوة والأذان والصلاحيات وإعادة التشغيل وقيود البطارية والمكالمات وتغيير المدينة واليوم وإعادة ضبط البيانات. `docs/ANDROID-ACCEPTANCE.ar.md` يسجل البنود غير منفذة. الاختبارات الآلية لا تثبت تسليم تنبيهات الخلفية على هواتف الشركات المختلفة.
3. **مراجعة دينية بشرية:** `assets/content/manifest.json:335` يسجل `human_review.status=pending` و`approved=false`. هذا سبب فشل فحص Release الفعلي. سلامة البصمات والمراجع لا تحل محل مراجعة مؤهلة للنصوص والصور والتسجيلات ومواقيت الصلاة.
4. **توافق أجهزة 16KB:** التقرير الموجود `docs/ANDROID-APK-2026-10-09.md` يسجل نجاح ZIP/LOAD مع إخفاق نهاية GNU_RELRO في ست مكتبات، وعدم اكتمال اختبار تشغيل 16KB. هذه أدلة سابقة للـAPK المطابق لبصمته الحالية، وليست إعادة تنفيذ لفحص ELF في هذه الجلسة أو إثباتًا لحدوث عطل. يلزم اختبار البيئة المناسبة قبل ادعاء توافق شامل. [مرجع أندرويد](https://developer.android.com/guide/practices/page-sizes).
5. **الحجم مرتفع:** صور المصحف وحدها 91,492,288 بايت، وهي محتوى مستخدم. حذف كاش المشروع لا يصغّر APK المبني بالفعل؛ قياس وتحسين حجم Release عمل مستقل لم يُنفذ.
6. **توثيق قديم متضارب:** `docs/content/PENDING_REVIEW.md` يذكر غياب صور المصحف والأذكار والأذان رغم وجودها ونجاح فحصها. `READINESS.md` في الجذر تقرير مرحلة قديمة مختلف عن `docs/READINESS.md`. بعض المتطلبات التاريخية تصف المدن والتنبيهات كميزات لم تُنفذ، بينما الكود الحالي يتضمنها. تحتاج الحالة الحالية تسوية مع إبقاء التقارير التاريخية واضحة.
7. **استضافة صفحة التحميل — اكتملت لاحقًا بموافقة المالك:** [صفحة التحميل العامة](https://zad-alruh.whiterat16.chatgpt.site) متاحة دون حساب. فُحص تنزيل APK كاملًا وطابق بصمة النسخة المحلية، ونجح استكمال التنزيل. تفاصيل التحديث في `docs/PUBLIC-DOWNLOAD.md`. بقية نواقص التطبيق أعلاه لم تتغير.
8. **بيانات المالك:** صفحة خصوصية منشورة ووسيلة دعم وبيانات الناشر النهائية غير جاهزة حسب `docs/store/OWNER-HANDOFF.md`. توجد إفصاحات داخل التطبيق. حسابات المتاجر تخص النشر بالمتاجر وليست شرطًا لإنشاء صفحة تحميل.
9. **iOS متوقف:** توجد مصادر iOS، لكن لا يوجد بناء أو اختبار أصلي معتمد على Mac. لم تُحذف المصادر أو التغييرات السابقة ضمن تنظيف أندرويد.

## التوزيع والتنظيف

صفحة عربية ثابتة في `dist/android/index.html`، بصور الواجهة واللوجو والمميزات وتعليمات التثبيت والخصوصية. زرا التنزيل يشيران إلى APK نفسه. أصول الصفحة نحو 233KB بالإضافة إلى HTML؛ لا تحتاج JavaScript أو خطوطًا خارجية أو حزم تشغيل.

نُظفت نواتج البناء والكاش والملفات المؤقتة المحددة بعد اكتمال التحقق، مع إبقاء الكود والتراخيص ومراجع المحتوى وتقارير الأدلة. قائمة الحذف والبصمة النهائية محفوظتان في `.local/oct09-cleanup-results.json`. لا تزال ملفات التصميم الأصلية ومصادر استيراد المحتوى موجودة لأنها مراجع لازمة وليست مخلفات.

خرج من مجلد المشروع نحو **4.91 GiB** موزعة على ٢٣ هدفًا. نُقلت الملفات إلى سلة المحذوفات لتظل قابلة للاسترجاع، ولم تُفرغ السلة؛ هذا تقليل لحجم مجلد المشروع وليس ادعاء تحرير هذه المساحة من القرص. بقي APK واحد فقط داخل المشروع، وبصمته لم تتغير. بقيت بعض مجلدات تجارب الاحتواء الصغيرة ذات junctions دون حذف تكراري لتجنب اتباع روابطها.

صفحة HTTP وأصولها الخمسة تعيد 200، وتدفق تنزيل APK بالكامل طابق البصمة السابقة دون إنشاء نسخة APK إضافية. فحص المتصفح على عرض 320 و390 و1440 بكسل لم يجد تمريرًا أفقيًا غير مقصود. أُجري فحص Flutter والمحتوى قبل إزالة الكاش؛ لم تُعد تشغيل هذه الأوامر بعد التنظيف لأنها ستعيد إنشاء الكاش، ولم يتغير كود التطبيق أو أصوله الأساسية.

للتجربة افتح `dist/android/index.html` مباشرة، أو من جذر المشروع:

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory dist/android
```

ثم افتح `http://127.0.0.1:8766/`. هذا رابط محلي على الكمبيوتر نفسه. النسخة العامة تستخدم مصدر استضافة مستقلًا في `.local/public-site`، يحتوي الصفحة وأصولها وأجزاء APK المضغوطة وخادم التنزيل فقط؛ لا يُنشر جذر المشروع أو كود Flutter. راجع `docs/PUBLIC-DOWNLOAD.md` قبل تحديث الاستضافة.

عند إصدار APK جديد، تحقّق منه أولًا ثم استبدل القديم وحدّث رابطَي التحميل والإصدار والحجم في الصفحة. Flutter يولد نسخًا مؤقتة عند البناء؛ نظّفها بعد اعتماد النسخة الجديدة للاحتفاظ بملف توزيع واحد.
