# Offline city data

Downloaded directly on 2026-09-27 from https://download.geonames.org/export/dump/cities15000.zip . The original UTF-8 tab-delimited file is bundled, along with the original readme/license. It contains 34,149 populated-place/capital records with coordinates and IANA timezones; it is not an exhaustive list of every settlement.
