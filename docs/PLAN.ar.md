## نتيجة فحص المشروع (٨ نوفمبر ٢٠٢٦)

المشروع Flutter كبير (~٧٠ ألف سطر، ~٥٣٠ اختبار) ومبني بعناية في طبقة البيانات (مواقيت، تنبيهات أصلية، قاعدة بيانات، تحقق من المحتوى). المشاكل الأساسية:

| # | المشكلة | الأثر |
|---|---|---|
| 1 | بناء Release ممنوع فعليًا: `build.gradle.kts` يرفض أي release من غير `key.properties` + معرف تطبيق جديد | النسخة الموزعة كانت **Debug بحجم ٢٨١ ميجا** وبطيئة |
| 2 | مفيش CI — البناء كان يدوي على ويندوز بمسارات عربي ومشاكل Java | صعب تطلع نسخة جديدة |
| 3 | ٦ تبويبات في الشريط السفلي (الحديث بعد المزيد) | زحمة وترتيب غريب |
| 4 | التصميم أخضر عام، خط الواجهة نفس خط النصوص، ألوان مكتوبة يدويًا في الشاشات | شكل قديم وغير متناسق |
| 5 | صفحة المصحف: ورقة بيضاء صغيرة جوه هوامش + شارة فوقها، الحبر رمادي (#202020)، مفيش وضع ليلي/سيبيا | الصفحة باينة أصغر وأقل وضوح |
| 6 | خط **Amiri Quran** متضمن في التطبيق بس مش مستخدم | حجم زيادة بلا فايدة |
| 7 | تقارير قديمة متضاربة (`READINESS.md` في الجذر، `PENDING_REVIEW.md`) | تلخبط أي حد يشتغل بعد كده |

ملحوظة: صور المصحف نفسها جودتها كويسة (١٢٠٠×١٩١٣، بدون فقد). التحسين بيكون في **طريقة العرض** مش في استبدال الصور (الصور عليها بصمات SHA-256 يتحقق منها التطبيق).

## إزاي تطلع نسخة

```bash
# تعديل رقم النسخة في pubspec.yaml مثلاً 0.4.0+4 ثم:
git tag v0.4.0 && git push origin v0.4.0
```
GitHub Actions يبني ويعمل Release فيه:
- `zad-alruh-<ver>-arm64-v8a.apk` ← لأغلب الموبايلات الحديثة
- `zad-alruh-<ver>-armeabi-v7a.apk` ← الموبايلات القديمة
- `zad-alruh-<ver>-universal.apk` ← لو مش عارف، ده بيشتغل على أي جهاز (حجمه أكبر)
